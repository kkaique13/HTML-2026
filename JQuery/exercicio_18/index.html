Tutorial: como fazer seu PC falar uma frase aleatória toda vez que você liga

  1. Abra o bloco de notas

    2. Pressione:

    Win + R → Digite notepad → Enter

    Cole isto:

    Set voz = CreateObject("SAPI.SpVoice")

    voz.Speak "Kaique, o sistema está operacional. O pato aguarda suas ordens."

  2. Salve o arquivo

    3. Clique em Arquivo → Salvar como

    Coloque:

    fala.vbs

    Em Tipo, escolha:

    Todos os arquivos

    Pode salvar na Área de Trabalho.

  3. Teste

    4. Dê dois cliques em fala.vbs

    Seu computador deverá falar a frase usando a voz do Windows.

  4. Faça acontecer toda vez que ligar o PC

    5. Pressione Win + R

    Digite:

    shell:startup

    E pressione Enter

    Vai abrir uma pasta. Agora simplesmente arraste o fala.vbs para dentro dela.

  5. Reinicie o PC

    6. Quando o Windows ligar novamente, ele vai dizer:

    "Kaique, o sistema está operacional. O pato aguarda suas ordens."
